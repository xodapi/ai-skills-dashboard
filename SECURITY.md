# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report vulnerabilities by emailing: **sbb@bsosh3.org**

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (optional)

You will receive a response within **48 hours**. If the issue is confirmed, a patch will be released as soon as possible.

## Scope

This policy applies to the `ai-skills-dashboard` repository, including:
- FastAPI backend (`backend/`)
- React frontend (`frontend/`)
- Scrapers (`scrapers/`)
- Docker/infrastructure configuration

## Out of scope

- Third-party dependencies (report to their maintainers)
- Issues already publicly disclosed
